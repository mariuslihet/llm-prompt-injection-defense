# Responsible disclosure

Do not test Mecha attacks against real third-party systems or users. Reproduce
suspected issues only against local fake-data fixtures. Preserve the seed,
policy digest, minimal payload, observed mock effects and regression test.
Do not post credentials, PII or private prompt contents in a public issue.

This local repository has no configured remote or disclosure address. Before a
public release the maintainer must enable private vulnerability reporting and
publish a monitored contact. Until then, provide a local minimal reproduction
to the operator without external publication. No response SLA or bounty is
promised. Host compromise and external tool implementations are outside the
current tested claims but may still identify important deployment risks.
