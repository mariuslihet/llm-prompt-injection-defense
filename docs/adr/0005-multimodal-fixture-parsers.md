# ADR 0005: Parse generated hidden-channel fixtures with established libraries

Accepted 2026-10-24. Add optional pypdf for real hidden-PDF text extraction and
Pillow for PNG metadata fixtures. They operate on files generated by this repo,
with input size and image dimensions bounded. No browser scripts, external
links, PDF actions or model-generated code execute. Metadata-only image tests
are not OCR evidence; OCR remains a separate requirement. Optional imports keep
the default offline gateway/test installation independent of media packages.
